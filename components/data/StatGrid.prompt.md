Big hero numbers, three or four to a row, one hairline grid rather than separate cards with shadows.

```jsx
<StatGrid stats={[
  { value: '132', label: 'Facilities mapped' },
  { value: '20', label: 'Local government areas' },
]} />
```

Reach for `StatRow` instead when the numbers sit inline in a dense header rather than as a hero. Three or four stats reads as a summary; more than five, use a table.
