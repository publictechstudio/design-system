A file row for an open-data downloads page. Stack several inside one outlined container, hairline-divided — never separate cards per file.

```jsx
<DownloadRow label="Facilities" meta="GeoJSON · 412 KB" url="./data/facilities.geojson" />
```

`meta` is always "Format · Size" — keep both, since format alone doesn't tell someone whether the download is worth the wait.
