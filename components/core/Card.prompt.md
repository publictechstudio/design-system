The house card — reach for it for any raised block; the 2px hover lift over 300ms ease-out is the brand's most repeated gesture.

```jsx
<Card media={ferryMap} mediaAlt="Lagos Ferry Map showing routes and terminals">
  <h3 style={{ fontSize: 'var(--text-card-title)', fontWeight: 700 }}>Lagos Ferry Map</h3>
  <p>The first comprehensive map of Lagos' ferry system…</p>
</Card>
```

Never add a border — depth is shadow only, with a hairline `border-top` inside the card when you need to separate a label row. Grid cards two-up on desktop for project work, three-up for services, with a 32px gap.
