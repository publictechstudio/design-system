A tinted pill for encoded status — reach for it only when the label carries data meaning, not for emphasis.

```jsx
<Badge tone="charter">Charter Only</Badge>
<Badge tone="planned">Future OMI EKO</Badge>
```

Text is bold 12px on a 15% tint of the same hue. Keep labels short and in the product's own vocabulary. For a plain content tag (destination names, categories) use `Pill` instead — badges signal state, pills signal membership.
