Tags a project with the capabilities it demonstrates — two or three per card, in a wrapping row above a hairline rule.

```jsx
<div style={{ display: 'flex', flexWrap: 'wrap', gap: 8 }}>
  <LabelChip tone="blue">Field data collection</LabelChip>
  <LabelChip tone="teal">Geospatial data</LabelChip>
  <LabelChip tone="green">Transit data</LabelChip>
</div>
```

Labels name a **discipline**, not a topic: "Field data collection", "Data visualization", "Content design", "SEO". Tone assignment is loose — vary hues across a grid so no two adjacent cards read the same. Text is uppercase here and nowhere else in the marketing register.
